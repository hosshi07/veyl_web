# Anomorph Archive

## 入口とファイル

`/anomorphs` を開きます。共通ナビゲーションの「アノモルフ」とトップ紹介セクションからアクセスできます。既存のトップ・ニュース・Arc・配布案内は維持しています。

## データ更新

既存ファイルは `src/components/home/home-sections.tsx` と `src/lib/navigation.ts` に導線を追加、`src/app/globals.css` にトップ側リンクのスタイルを追加しました。`src/app/layout.tsx` にはスムーズスクロールを使うことを示すNext.js用属性を追加しています。`package.json` と `tsconfig.json` はテスト実行・型確認用、`README.md` と `docs/architecture.md` は現在の構成に合わせて更新しました。既存の依存パッケージは追加・更新していません。

資料のID・名前・画像・文章は `archive-records.json` の現在の内容をそのまま使用します。今回の挙動改善ではデータを変更していません。`sample: true` の資料には仮データの注記を表示します。

JSONのフィールドは `id`, `name`, `image`, `phrase`, `teaser`, `sample`。画像は `public/` 以下のパスか `null` を指定します。画像取得に失敗した場合もプレースホルダーを表示します。正式データを確認して差し替えたら `sample: false` にします。IDは一意かつ固定にしてください。

取得層は公開フィールドだけを明示的に返すため、ランク・出身・能力などはこの画面へ渡しません。CMS導入時は `getArchiveRecords` を同じ型で置換します。将来の検索・ジャンプは既存の `jump` アクションを利用できます。

## 操作と状態

- PC：ホバーで部分プレビュー、クリックで開く。右から左へ戻る際は、選択中の紙の左半分を越えると一つ左へ選択を渡します。
- スマートフォン幅またはタッチ入力：1回タップでプレビュー、2回目で開く。「プレビュー解除」で戻す。
- PCは資料領域や紙の上から左右にドラッグ、スマートフォンは左右スワイプで循環移動。移動量に応じて複数件を通過し、離した直前の速度で慣性移動して徐々に減速します。動いている紙や空間を押さえると、その場で停止します。この停止操作では詳細を開きません。
- 前後ボタンと矢印キーは、アニメーション中でも操作ごとに1件ずつ反映。Home / Endで先頭・末尾へ。
- ホイールは常にページの縦スクロール。資料切り替えとON/OFFボタンは廃止しました。
- 資料領域またはタブでEnter / Spaceを押して開く。
- 閉じるボタン、Escape、背景クリックで復帰。抽出中の閉じる要求は保持し、抽出後に戻す。
- 詳細中は背景をinertにし、スクロールを固定。閉じた後は元の並び・スクロール・タブのフォーカスを保持。
- テキスト形式の閲覧手段をページ下部に用意。こちらはJavaScriptなしでも使用可能。

状態は `idle → opening → reading → closing → idle`。同じ紙のDOM要素に位置・角度・拡大率のキーフレームを適用します。先頭のnullキーフレームでホバーなどの現在位置を引き継ぎ、クリック時の跳ねを防止します。完了通知で状態を進め、同期refで操作を順番に反映します。旧来の380msの入力制限は撤去し、抽出・閲覧・復帰中だけ資料切り替えを止めます。水平移動の開始後にポインターを捕捉し、資料外まで動かしても終了を検出します。ドラッグ後のクリックを抑止し、誤って詳細を開くことを防ぎます。縦方向のタッチ移動はブラウザーのスクロールへ委ねます。

整数の資料番号と小数部分を持つ連続位置を用い、PCは5枚＋境界の1枚、狭い画面は3枚＋境界の1枚だけ描画します。境界の紙は透明度が0になるまで移動方向に沿って移動し、反対端から同じ方向へ現れます。下方向への退出アニメーションは使用しません。周回しても仮想スロットのキーを保ち、同じ紙が反対端へ突然飛ばないようにしています。

減衰と速度上限は `DECK_PHYSICS`、角度・上下ずれ・左右位置・透過は `paperPose` に分離しています。黒い紙や平行配置へ変更する場合も、物理計算と資料データを変えずに外観・配置を変更できます。ログは直近4行に限定します。

端末のアニメーション軽減設定では移動を即時化して閲覧を維持します。新たな3Dライブラリ・依存パッケージ・認証システムは追加していません。

## 検証と残りの確認

最終確認では本番ビルド・型チェック・整形チェックが成功し、単体テスト13件が通りました。`/` と `/anomorphs` の静的生成を確認済みです。引き抜き・復帰後の資料順序とスクロール位置、背景のロック解除も確認しました。ブラウザーの実行エラーはありません。表示確認画像は `archive-preview.png`、`archive-detail.png`、`archive-mobile.png` です。

`npm run typecheck`、`npm test`、`npm run format:check`、`npm run build` を使用します。`npm test` のTypeScript直接実行はNode.js 22.6以降が必要です（実行環境はNode.js 24）。

ブラウザー確認対象：PC表示、幅390px、2段階プレビュー・選択、マウスプレビュー、引き抜きと復帰、矢印キー・Enter・Escape・Tab、空間・紙の上からの左右ドラッグ、減衰する慣性・押さえて停止、左右へ戻る選択、ホイールの通常スクロール、操作ログ、既存トップ・ニュース。

追加確認対象：実機スマートフォンでの指のスワイプ、OSのアニメーション軽減設定、ブラウザー間の体感差。スワイプ方向・縦スクロールの除外は単体テストで検証します。

正式データと追加画像、ID検索UIは未設定。セッションは別ページへ移動すると初期化します。非常に短い画面では紙を縮小するため、テキスト版も利用できます。

参考：[Motionのキーフレーム](https://motion.dev/docs/react-animation)、[アニメーション軽減](https://motion.dev/docs/react-accessibility)。
